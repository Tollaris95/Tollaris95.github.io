Web front end — Next.js / React

Problem
Server state and UI state tended to drift apart, and every editorial change to the song catalog required a deployment.
Decision
Strict separation between server state (TanStack Query) and app state (Redux Toolkit); the catalog moved out of the code into a model editable from the admin back office, falling back to defaults until something is configured.
Outcome
Cache and UI stay consistent, and the team curates the catalog without shipping code.

Learning web app: interactive sheet music and keyboard, progression game, PianoConvert in the browser, Stripe subscription funnel. App Router, MUI, CMS-driven multilingual copy, screens built from Figma designs.

API — Sails.js / MongoDB

Problem
A single API serves several clients (web, mobile, extension), with authentication to share and payment webhooks that must be reliable.
Decision
Sails.js REST on MongoDB (data modeling, indexing, aggregations), OAuth2/OIDC authentication via Keycloak with a JWT secret specific to this backend, idempotent Stripe webhooks, BullMQ/Redis background jobs.
Outcome
A single, secure entry point for every client; about 1,450 API and front-end test cases, with CI blocking on lint and dependency audit.

Audio → sheet-music transcription pipeline

Audio processing (Essentia, MuseScore) is too heavy to live inside the API's request/response cycle. I moved it to concurrent BullMQ/Redis workers, with one idempotency key per conversion so the same file is never processed twice, conditional state transitions, and a priority queue that lets short conversions overtake long ones.

Exposing the platform to AI agents

A Model Context Protocol server gives AI agents controlled access to GA4, Stripe, MongoDB and BigQuery. The hard part is not the data being exposed but the door: OAuth2/OIDC, short-lived JWT/JWKS tokens, and ten scopes that decide what an agent can read or write, per tool and per role.

PianoConvert Chrome Extension

2024 – 2026

Turn a YouTube video into sheet music without leaving the YouTube page.

Manifest V3 extension published on the Chrome Web Store, built with Plasmo, about 10,700 lines of TypeScript. A script injected into the YouTube page can neither call the API nor handle authentication directly: everything goes through a background service worker, connected by message passing, which handles OAuth2 via chrome.identity, direct uploads to S3 and real-time conversion tracking over WebSocket. A detection module analyzes the video content to suggest which instrument to transcribe.

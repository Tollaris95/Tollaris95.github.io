Serveur MCP

2026

Exposer des données de production à des agents IA sans leur donner les clés du système.

Un serveur Model Context Protocol qui donne à des agents IA un accès contrôlé à GA4, Stripe, MongoDB et BigQuery. Le vrai sujet n'est pas la donnée exposée mais la porte entre l'agent et le système : authentification OAuth2/OIDC via Keycloak, jetons JWT/JWKS de courte durée, et dix scopes qui déterminent précisément ce qu'un agent peut lire ou écrire, par outil et par rôle.

Extension Chrome PianoConvert

2024 – 2026

Convertir une vidéo YouTube en partition, sans quitter la page YouTube.

Extension Manifest V3 publiée sur le Chrome Web Store, construite avec Plasmo. Un script injecté dans la page YouTube ne peut ni appeler l'API ni gérer l'authentification directement : tout passe par un service worker en arrière-plan, relié par passage de messages, qui porte l'OAuth2 via chrome.identity, l'upload direct vers S3 et le suivi de conversion en temps réel par WebSocket.

Manifest V3Plasmochrome.identity Redux ToolkitWebSocketChrome Web Store

Pipeline PianoConvert & GalaxyConvert

2023 – 2026

Sortir la conversion audio → partition du serveur web avant qu'elle ne le mette à genoux.

Le traitement audio (Essentia, MuseScore) est trop lourd pour vivre dans le cycle requête/réponse d'une API. Je l'ai extrait vers des workers BullMQ/Redis concurrents, avec une clé d'idempotence par conversion pour ne jamais traiter deux fois le même fichier, des transitions d'état conditionnelles, et une file priorisée qui laisse les conversions courtes doubler les longues plutôt que d'attendre en ligne.
